SMARTWOOD ANDROID APP — UPDATED PROTOTYPE

This Android Studio project contains a mobile-friendly SmartWood order and production monitoring prototype.

FEATURES
- Home and product catalogue
- Customer order form and reference number
- Order details lookup using order reference + email
- Quotation request form and employee quotation inbox
- Employee sign-in and workspace dashboard
- Update order and quotation statuses
- Manage indicative product prices
- Reports and CSV export
- Sample production monitoring data
- Sonae Arauco Commercial Office contact details

OPEN IN ANDROID STUDIO
1. Extract SmartWoodAndroidApp.zip.
2. Android Studio > File > Open, select the SmartWoodAndroidApp folder containing settings.gradle.
3. Allow Gradle sync. Install Android SDK 35 if requested.
4. Run on an emulator or Android phone.

IMPORTANT LIMITATIONS
This is a front-end prototype. Orders, quotes, session and demo prices are stored in local storage on the device and are not transmitted to Sonae Arauco. For real multi-user sign-in, shared order monitoring, email notifications, company price data and payment processing, connect a secure backend/database and configure authentication. Sample production readings are illustrative, not live factory data. Customer orders can be looked up with their reference and email.

The Contact page uses the Commercial Office details provided by the user. The email enquiry form opens the device's configured email application.
